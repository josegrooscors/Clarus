# Clarus

Gestión en punto de venta: ruta, check-in/out con GPS, gestión, fotos en vivo, inventario (unidades → kg), promociones y pedidos con escaneo de la orden física.

- `app/` — aplicación web instalable (PWA). Móvil, tablet y escritorio.
- `supabase/` — base de datos (migraciones) y funciones del servidor.

Backend: Supabase (proyecto `clarus`).
